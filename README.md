# Luna Speaker Landing Page

A responsive landing page for the Luna wireless speaker concept.

## Demo

[Live Demo](https://antonyshaga.github.io/kickstarter-landing/)

## Technologies

* HTML5
* SCSS
* JavaScript
* BEM
* Parcel

## Features

* Responsive layout for desktop, tablet, and mobile devices
* Mobile navigation menu
* Interactive sliders
* Responsive images using `<picture>`
* SVG sprite icons
* Contact form
* Smooth navigation between page sections

## Getting Started

Clone the repository:

```bash
git clone https://github.com/AntonyShaga/kickstarter-landing.git
```

Install dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm start
```
